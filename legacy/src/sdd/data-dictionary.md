# Data Dictionary - IAS

## 🧩 Domain Entities

### MediaSource
Represents the source of multimedia and its extraction state.
*Location: `src/ias/modules/media_ingestion/domain/entities.py`*

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `id` | `MediaId` (str) | Yes | - | Unique identifier (UUID V4) |
| `url` | `str` | Yes | - | Source URL (YouTube) |
| `status` | `MediaStatus` (Enum) | Yes | `PENDING` | pending, processing, completed, failed |
| `title` | `str` | No | `""` | Video title (extracted from metadata) |
| `audio_path` | `str` | No | `""` | Local path to the extracted .mp3 file |

### SpeechTranscript
Represents the transcribed text from an audio source.
*Location: `src/ias/modules/speech_processing/domain/entities.py`*

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `id` | `TranscriptId` (str) | Yes | - | Unique identifier (UUID V4) |
| `media_id` | `str` | Yes | - | Reference to the original MediaSource |
| `audio_path` | `str` | Yes | - | Path to the source audio |
| `text` | `str` | No | `""` | Full transcription text |
| `status` | `SpeechStatus` (Enum) | Yes | `PENDING` | pending, processing, completed, failed |

### KnowledgeNode
Represents the final structured knowledge entry in the vault.
*Location: `src/ias/modules/knowledge_compilation/domain/entities.py`*

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `id` | `NodeId` (str) | Yes | - | Unique identifier (UUID V4) |
| `media_id` | `str` | Yes | - | Reference to the original MediaSource |
| `title` | `str` | Yes | - | Knowledge node title |
| `content` | `str` | No | `""` | Synthesized Markdown content |
| `tags` | `List[str]` | No | `None` | Semantic tags generated by LLM |
| `status` | `CompilationStatus` (Enum) | Yes | `PENDING` | pending, compiling, completed, failed |

## 🔢 Enums

### MediaStatus
- `PENDING`: Waiting for extraction.
- `PROCESSING`: Downloading/Extracting audio via yt-dlp.
- `COMPLETED`: Audio file saved and metadata collected.
- `FAILED`: Extraction or download error.

### SpeechStatus
- `PENDING`: Waiting for transcription.
- `PROCESSING`: Local Whisper inference running.
- `COMPLETED`: Text transcript available.
- `FAILED`: GPU/Inference error.

### CompilationStatus
- `PENDING`: Waiting for synthesis.
- `COMPILING`: Local LLM (Ollama) processing text.
- `COMPLETED`: Markdown file saved in vault.
- `FAILED`: LLM or Vault I/O error.
